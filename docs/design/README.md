# Design records

These documents describe proposals and decisions at the time they were written.
Use [current architecture notes](../architecture/README.md) for shipped
behavior.

| Record                                                                         | Status                                                                      |
| ------------------------------------------------------------------------------ | --------------------------------------------------------------------------- |
| [Cloud vision](factory-factory-cloud-vision/README.md)                         | Proposed; includes a possible MVP plan                                      |
| [Adversarial review](adversarial-review.md)                                    | Implemented; the record identifies its remaining live-validation limitation |
| [Clipboard screenshot paste](clipboard-screenshot-paste-unsupported-format.md) | Option A implemented; alternatives remain design context                    |
| [Archive](archive/)                                                            | Superseded designs and migration records                                    |

Top-level `docs/design-*.md` and `docs/workspace-notification-design*.md` are
also point-in-time records. Their proposed paths and APIs may differ from the
current implementation. Keep a proposal's status explicit; implementation steps
do not authorize work unless the current task selects them.
