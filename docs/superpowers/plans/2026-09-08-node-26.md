# Node 26 Implementation Plan

> **For agentic workers:** Execute inline with the executing-plans workflow; use a read-only reviewer before opening the PR.

**Goal:** Move development, CI, release jobs, and Docker to Node 26.8.1, with Node 26 as the CLI/development minimum. Electron continues to use its bundled Node runtime.

**Architecture:** Keep pnpm 10.34.5 and all unrelated dependency versions unchanged. Replace Docker's bundled-Corepack assumption with pnpm's versioned standalone binary, verified against a pinned SHA-256 digest. Disable Node's experimental Web Storage in Vitest workers so jsdom owns browser storage.

**Tech Stack:** Node 26.8.1, pnpm 10.34.5, TypeScript 5.9, Vitest 4, Docker Alpine.

**Spec:** User-approved serial major dependency upgrades, including Node 26. Start only after ACP #2223 merges; wait for this PR's merge before the next upgrade.

## Constraints

- Use pnpm for repository dependency operations.
- Keep npm publishing through the existing staged OIDC flow.
- Run all required guardrails and normal commit hooks.
- Keep the root checkout and other worktrees unchanged.
