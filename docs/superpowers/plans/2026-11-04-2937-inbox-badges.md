# Workspace unread inbox badges implementation plan

**Goal:** Surface unread inbox mail on the Inbox tab, workspace cards and
sidebar rows without changing read/acknowledgement behavior.

**Historical approach selected:** add a trusted project aggregate in the
workspace capsule and feed one shared query into sidebar, board and tools
presenters. Preserve the existing unread/read/acknowledgement contract. The
current behavior belongs in
[Child workspaces](../../architecture/agent-runtime.md#child-workspaces).

- [x] Add failing accessor tests for aggregation, unread semantics and project
      scoping; implement resource/service/trusted tRPC output.
- [x] Add badge/query regression coverage; wire shared counts to
      tab/cards/sidebar and invalidate after existing read/ack mutations.
- [x] Cover zero/unread/high count and phone states in Storybook; update current
      inbox docs and run applicable checks/tests/browser stories.
- [ ] Independent review, ready PR, resolve CI/comments, serialized green merge.

Verification record: backend count/trust and focused client regressions pass.
The full application pass exposed two old tRPC mocks without the new query;
those fixtures were updated and all 24 affected regressions pass. The full
Storybook run rendered all 1,114 stories but reported three missing response
errors from the existing tools fixture; its count response was added. Both full
suites are rerun as delivery gates. No assertions or checks were weakened.
