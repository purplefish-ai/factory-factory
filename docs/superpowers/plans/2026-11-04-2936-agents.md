# Agents controls implementation plan

> Execute inline with superpowers:executing-plans and test-driven-development.

**Goal:** Make creation explicit by kind and group the Agents rail while
preserving existing permissions, routes and event authoring limits.

**Architecture:** The shell owns one shared Create menu and Scheduled/Event rail
sections. The controller selects scheduled or event creation explicitly. Route
composition injects the existing workspace composer for conversational event
authoring, avoiding an agents/kanban dependency cycle. Event drafts have a
separate purpose identity; regular and scheduled workspace drafts stay intact.

**Tech stack:** React, TypeScript, tRPC, Radix menus, Vitest, Storybook,
Playwright. Node 26.12.1, pnpm 12.15.0.

**Spec:**
[Issue #2936](https://github.com/purplefish-ai/factory-factory/issues/2936) and
the approved execution contract in `/private/tmp/ff-2936/contract.md`.

## Defaults and alternatives

Scheduled opens the existing schedule form. Event opens guidance plus a normal
workspace composer seeded to propose a paused event agent; the proposal still
requires review and explicit creation. Direct event CRUD and activation were
rejected because the current authoring contract does not support them. Composer
injection from the route avoids circular feature imports. Existing per-kind IDs,
query errors, cached rows, load-more and mobile stacking are preserved.
