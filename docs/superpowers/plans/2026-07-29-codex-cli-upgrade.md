# Codex CLI 0.145.0 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the Codex CLI release enforced by CI from `0.101.0` to `0.145.0` and commit the matching app-server schema snapshot.

**Architecture:** Keep the CI install on an exact, reproducible version and regenerate the existing schema snapshot with that same CLI release. Preserve the current drift-checking script and all unrelated Codex installation behavior.

**Tech Stack:** GitHub Actions, Node.js 22, pnpm, `@openai/codex`, Codex app-server TypeScript schema generation

## Global Constraints

- The exact CI version must be `@openai/codex@0.145.0`.
- The snapshot must be generated by Codex CLI `0.145.0`.
- Leave the Dockerfile's unpinned Codex install unchanged.
- Do not change application behavior, models, prompts, runtime dependencies, or the schema-drift script.
- Unexpected removed app-server methods require investigation before acceptance.

---

### Task 1: Update the CI Pin and App-Server Schema Snapshot

**Files:**
- Modify: `.github/workflows/ci.yml`
- Modify: `src/backend/services/session/service/acp/codex-app-server-adapter/schema-snapshots/app-server-methods.snapshot.json`

**Interfaces:**
- Consumes: `pnpm check:codex-schema:update`, which invokes `codex app-server generate-ts`
- Produces: an exact CI installation of `@openai/codex@0.145.0` and a snapshot whose `codexCliVersion` is `codex-cli 0.145.0`

- [ ] **Step 1: Confirm the old snapshot rejects Codex CLI 0.145.0**

Run:

```bash
CODEX_SCHEMA_CHECK=strict pnpm check:codex-schema
```

Expected: FAIL with `expected codex-cli 0.101.0, got codex-cli 0.145.0`.

- [ ] **Step 2: Update the exact CI version**

Change the install command in `.github/workflows/ci.yml` to:

```yaml
- name: Install Codex CLI
  run: npm install -g @openai/codex@0.145.0
```

- [ ] **Step 3: Confirm the local generator uses the target release**

Run:

```bash
codex --version
```

Expected: `codex-cli 0.145.0`.

- [ ] **Step 4: Regenerate the app-server method snapshot**

Run:

```bash
pnpm check:codex-schema:update
```

Expected: the command reports that it updated
`src/backend/services/session/service/acp/codex-app-server-adapter/schema-snapshots/app-server-methods.snapshot.json`.

- [ ] **Step 5: Review the generated schema delta**

Run:

```bash
git diff -- .github/workflows/ci.yml src/backend/services/session/service/acp/codex-app-server-adapter/schema-snapshots/app-server-methods.snapshot.json
```

Expected: the CI pin and `codexCliVersion` change to `0.145.0`; added methods
are accepted as upstream schema additions. Stop and investigate if any method
is removed.

- [ ] **Step 6: Verify strict schema drift detection**

Run:

```bash
CODEX_SCHEMA_CHECK=strict pnpm check:codex-schema
```

Expected: PASS with `codex app-server schema snapshot is up to date`.

- [ ] **Step 7: Run repository verification**

Run each command independently:

```bash
pnpm check
pnpm typecheck
pnpm test
pnpm build
```

Expected: every command exits successfully with no test failures, type errors,
lint violations, dependency-boundary violations, or build errors.

- [ ] **Step 8: Inspect and commit the upgrade**

Run:

```bash
git diff --check
git status --short
git diff --stat
git add .github/workflows/ci.yml src/backend/services/session/service/acp/codex-app-server-adapter/schema-snapshots/app-server-methods.snapshot.json
git commit -m "Update Codex CLI to 0.145.0"
```

Expected: only the CI workflow and generated schema snapshot are added by this
commit, and the commit succeeds.
