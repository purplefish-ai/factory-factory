# Electron 44 Upgrade Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Upgrade Electron to 44.3.0, preserve clipboard image paste, and make the desktop package start its Electron entry point.

**Architecture:** Migrate main-process clipboard reads to `clipboard.read()` and decode image blobs through `nativeImage` before returning PNG over the existing IPC channel. Keep authorization and size checks. Override only packaged desktop metadata so the npm CLI keeps its entry point.

**Tech Stack:** Electron 44.3.0, Node 26.8.1 development runtime, pnpm 12.3.4, Vitest 5.

**Spec:** User-approved sequential dependency upgrades; follows merged #2248. Existing Electron packaging entry mismatch was queued with this upgrade.

## Constraints

- Preserve clipboard IPC name, PNG response, trusted main-frame restriction, and 10 MiB limit.
- Document Electron 44's macOS 13 minimum.
- Do not change the npm CLI entry point or merge the PR.

## Validation and packaging findings

- Baseline: 5,476 tests passed, 4 skipped. Electron-specific compilation reproduced the removed `readImage` API; updated clipboard tests failed before migration.
- Final suite: 5,483 tests passed, 4 skipped; 34 Electron tests cover async image conversion, limits, frame authorization across navigation/closure, and compiled sandbox preload IPC.
- Backend/frontend build and Electron compilation pass. Electron 44.3.0 runs bundled Node 24.20.0; backend migrations and database health pass under that runtime.
- An unsigned macOS ARM64 directory package builds without an entry override. Package startup exposed missing shared/lib runtime files, which are now included and unpacked alongside the backend.
- Packaged renderer initially had no preload bridge because sandboxed preloads cannot load its ESM output. The preload is now `.cts` → `.cjs`, compiled under NodeNext and tracked by Knip. The new preload regression test compiles the actual config into a temporary directory and executes it in a CommonJS sandbox.
- A smoke harness loads the packaged entry with an isolated temporary user-data directory. The app migrates its database and renders its workspace UI; fixture JPEG clipboard data travels through the real Electron ClipboardItem/nativeImage APIs and trusted renderer IPC as PNG.
- Node 26 native modules are restored after Electron verification. No signed distribution or Windows/Linux desktop package is produced locally.
- Packaged native PTY spawn/output check passes. Frozen install, formatting, typecheck, strict guardrails, Knip, and audit pass with no known vulnerabilities.
