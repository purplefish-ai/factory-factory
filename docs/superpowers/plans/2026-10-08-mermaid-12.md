# Mermaid 12 upgrade

Upgrade Mermaid 11.17.2 to stable 12.1.0 separately from the dependency security
fixes. Preserve the existing diagram presentation with explicit
`theme: 'default'`, `look: 'classic'`, and `layout: 'dagre'` initialization.
Mermaid 12 otherwise changes layout and appearance defaults. Diagram authors can
still request a different appearance through frontmatter.

Keep `securityLevel: 'strict'`, `startOnLoad: false`, and
`suppressErrorRendering: true`. Strict security cannot be relaxed through
diagram frontmatter. Markdown still loads the engine lazily, and incomplete
diagrams use the existing error display and recover after their source becomes
valid.

[Mermaid 12.0 migration notes](https://github.com/mermaid-js/mermaid/releases/tag/mermaid@12.0.0)
also remove `defaultRenderer` from flowchart, class, and state configuration.
The application does not set it; diagram authors should use top-level `layout`
instead. The runtime now targets ES2024 and requires Safari 17.4+ and Node
22.12+. The project's Node 26.8.1 requirement meets that floor. Older Safari
versions are not covered by this upgrade's verification.

[Mermaid 12.1 release notes](https://github.com/mermaid-js/mermaid/releases/tag/mermaid@12.1.0)
include parser dependency security fixes and a linear frontmatter scanner.

## Verification

- Real-engine regressions failed for flowchart, class, and state diagrams before
  the compatibility settings: their effective layout changed to `elk`.
- All eight tests across `mermaid-diagram.integration.test.tsx`,
  `mermaid-diagram.test.tsx`, and `markdown-loading.test.tsx` pass with 12.1.0.
  These cover effective appearance, strict security, lazy loading,
  invalid-source recovery, and stale asynchronous rendering.
- Chromium Storybook smoke checks pass for flowchart, class, state,
  invalid-source error display without an error SVG, and recovery to a valid
  SVG. No page errors were emitted. Class and state stories were added for
  future visual review.

The independent branch also pins KaTeX 0.18.2 because Mermaid 12 still requests
its older vulnerable release line. This preserves the security fix when the
Mermaid and dependency PRs are reviewed separately. The production build adds a
lazy ELK chunk of about 1.46 MB (456 kB gzip), even with the Dagre presentation
selected.

Repository-wide verification on the independent branch passes: `pnpm check:fix`,
`pnpm typecheck`, `pnpm test` (6,246 passed, four skipped), `pnpm check`,
production build, and Storybook build. The local Codex schema check skips due
the installed CLI version mismatch; CI enforces the repository's pinned CLI.
