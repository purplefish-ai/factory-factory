# Historical milestone planning

The v1.0–v1.2 milestones in this directory completed in February 2026.
`STATE.md`, `PROJECT.md`, `ROADMAP.md`, `milestones/`, `phases/`, and
`research/` preserve those milestones' scope, decisions, and execution evidence.
Their descriptions of the "current" state apply to that period, and are not the
current roadmap or instructions to resume work.

`codebase/` contains generated snapshots last analyzed in May 2026. Paths,
dependencies, commands, and architecture descriptions may have changed. Use the
[documentation index](../docs/README.md) and
[current architecture notes](../docs/architecture/README.md) for ongoing work.

Keep these records available for historical questions. New work should identify
its own scope and status rather than updating a completed milestone's state or
regenerating these maps as another source of current guidance.
